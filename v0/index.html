AI Demo Video Automation Platform

Industry project · 2026

Automatically generates recorded product demo videos for bid and tender submissions, straight from requirement documents and source code.

Purpose: Bid and tender submissions often require recorded product demo videos. Recording, narrating, and editing them by hand is slow and error-prone. The platform generates these videos automatically from requirement documents and the product's source code.

My contributions:

  • Built an analysis skill that runs a coding agent (Codex) over requirement documents and source code and outputs a structured list of product features with menu locations and steps.
  • Implemented recording-plan generation with a rule-based high-risk-action scanner (e.g. delete or payment actions are forced to "high risk" and need human confirmation).
  • Built the recording pipeline: Playwright drives the browser, ffmpeg records and merges video, and text-to-speech produces narration. Narration is generated first and its duration sets the recording pace, so audio and video stay aligned.
  • Built parts of the web workbench (Vue 3) and backend (Java / Spring Boot): recording queue, progress, pause/stop, retry, and result review.

Tech: Java 21, Spring Boot, Vue 3, PostgreSQL, Playwright, ffmpeg, Codex CLI.

Lecture Transcript × Slides Note Linker

Personal project · 2026

Aligns a lecturer's spoken explanations with the matching slides to turn lecture recordings into easy-to-review study notes.

Purpose: Turn lecture recordings into study notes that are easy to review by aligning the lecturer's spoken explanations with the matching slides.

My contributions:

  • Designed a reusable agent skill that takes a lecture transcript (Zoom or Feishu Minutes subtitles) and the lecture PDF, then aligns explanations with slides page by page.
  • Produces a structured Markdown note per lecture in Obsidian with key concepts, explanations, and cross-links.
  • Used it across several MSc courses (NLP, Computer Vision, LLM for Agents, Agentic Computing).

Tech: Codex / Claude Code agent skills, Markdown, Obsidian.
