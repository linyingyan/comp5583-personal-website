Coursework / Graduation Project

Ancient Chinese Book OCR & Knowledge Extraction System

Mar – May 2026 · Role: full-stack developer (sole developer of architecture and core features)

Turns scanned ancient Chinese books — printed in vertical, right-to-left columns — into ordered text and a searchable, traceable knowledge base for digital-humanities research.

Purpose: Scanned ancient Chinese books are printed in vertical, right-to-left columns that general OCR tools read in the wrong order, and their content (people, events, places, relations) is hard to search or analyse. The system turns scanned books into ordered text and a searchable, traceable knowledge base for digital-humanities and historical research.

Contributions:
  • Designed the system architecture and connected the full pipeline: upload document → OCR → LLM structured extraction → database → knowledge graph and spatio-temporal analysis.
  • Built the OCR module: render PDF pages at high resolution, run PaddleOCR, then restore reading order for vertical text by grouping text boxes into columns by x-coordinate (right to left) and sorting each column top to bottom. Supports images and multi-page PDFs.
  • Built an LLM extraction pipeline for entities, knowledge triples, summaries, modern translations and spatio-temporal events; added long-text chunking, fallback JSON parsing and field de-duplication to make the output stable.
  • Built the knowledge-graph module (triples stored in the database, relation search, statistics, person-relationship network visualisation) and a spatio-temporal module that clusters events across documents into timelines with links back to the source evidence.
  • Added batch OCR and extraction, file-hash caching and per-record re-extraction.

Tech: Python, FastAPI, Vue 3, PaddleOCR, PyMuPDF, SQLAlchemy, SQLite, ECharts, OpenAI-compatible LLM API.

AI Demo Video Automation Platform

2026

Generates product demo videos automatically from requirement documents and source code, for bid and tender submissions. Company and client names are withheld.

Purpose: Bid and tender submissions often require recorded product demo videos. Recording, narrating and editing them by hand is slow and error-prone. The platform generates these videos automatically from requirement documents and the product's source code.

Contributions:
  • Built an analysis skill that runs a coding agent (Codex) over requirement documents and source code and outputs a structured list of product features with menu locations and steps.
  • Implemented recording-plan generation with a rule-based high-risk-action scanner (e.g. delete or payment actions are forced to "high risk" and need human confirmation).
  • Built the recording pipeline: Playwright drives the browser, ffmpeg records and merges video, and text-to-speech produces narration. Narration is generated first and its duration sets the recording pace, so audio and video stay aligned.
  • Built parts of the web workbench (Vue 3) and back end (Java / Spring Boot): recording queue, progress, pause/stop, retry and result review.

Tech: Java 21, Spring Boot, Vue 3, PostgreSQL, Playwright, ffmpeg, Codex CLI.

Highly Cited Scientists Analysis

Mar 2024 – Mar 2025 · Role: data processing lead; second principal investigator

Collected and analysed data on highly cited scientists and papers from China's "985" universities (2009–2023) to support discipline evaluation and talent-recruitment decisions.

Purpose: Collect and analyse data on highly cited scientists worldwide and highly cited papers from China's "985" universities (2009–2023), using ESI, Web of Science and InCites, to support discipline evaluation and talent-recruitment decisions.

Contributions:
  • Bulk-downloaded and organised Web of Science records of highly cited and hot papers from 985 universities, and merged and cross-checked the data from multiple universities.
