Coursework / Graduation Project

Ancient Chinese Book OCR & Knowledge Extraction System

Mar – May 2026 · Role: full-stack developer (sole developer of architecture and core features)

Purpose: Make scanned ancient Chinese books searchable for digital-humanities and historical research.

Delivered capability: Ordered text from vertical, right-to-left pages, searchable knowledge graphs and cross-document event timelines linked to source evidence.

My contributions:
  • I designed the system architecture and connected the full pipeline: upload document → OCR → LLM structured extraction → database → knowledge graph and spatio-temporal analysis.
  • I built an OCR module for images and multi-page PDFs using PyMuPDF to render PDF pages at high resolution and PaddleOCR to recognise text. I restored vertical reading order by grouping text boxes into columns by x-coordinate (right to left) and sorting each column top to bottom.
  • I built an LLM extraction pipeline for entities, knowledge triples, summaries, modern translations and spatio-temporal events; added long-text chunking, fallback JSON parsing and field de-duplication to make the output stable.
  • I built the knowledge-graph module (triples stored in the database, relation search, statistics, person-relationship network visualisation) and a spatio-temporal module that clusters events across documents into timelines with links back to the source evidence.
  • I added batch OCR and extraction, file-hash caching and per-record re-extraction.

Tech: Python, FastAPI, Vue 3, PaddleOCR, PyMuPDF, SQLAlchemy, SQLite, ECharts, OpenAI-compatible LLM API.

Evidence limit: Measured OCR and extraction accuracy are not supplied.

AI Demo Video Automation Platform

2026

Purpose: Automate product demo videos for bid and tender submissions from requirement documents and source code.

Delivered capability: Browser recordings paced to generated narration, with human confirmation required for high-risk actions. Company and client names are withheld.

My contributions:
  • I built an analysis skill that runs a coding agent (Codex) over requirement documents and source code and outputs a structured list of product features with menu locations and steps.
  • I implemented recording-plan generation with a rule-based high-risk-action scanner (e.g. delete or payment actions are forced to "high risk" and need human confirmation).
  • I built the recording pipeline using Playwright for browser control, ffmpeg for recording and merging video, and text-to-speech for narration. I generated narration first and used its duration to set the recording pace.
  • I built parts of the web workbench (Vue 3) and back end (Java / Spring Boot): recording queue, progress, pause/stop, retry and result review.

Tech: Java 21, Spring Boot, Vue 3, PostgreSQL, Playwright, ffmpeg, Codex CLI.

Highly Cited Scientists Analysis

Mar 2024 – Mar 2025 · Role: data processing lead; second principal investigator
